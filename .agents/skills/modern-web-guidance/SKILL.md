# Modern Web Guidance

Standards for cutting-edge web applications:
- Semantic HTML and accessible ARIA attributes.
- Modern CSS: Container queries, :has(), CSS Grid, and View Transitions.
- Performance: Core Web Vitals optimization (LCP < 2.5s, low INP).
